# この1年で調べて試したIT関連の取り組み

この1年で試したIT関連の取り組みを4つ紹介します。1つ目は、複数のAIエージェントに役割を分けて作業を進める方法です。2つ目は、自分のPCで起きたゲーム映像のカクつきを調査し、原因のサービスを特定して数値で改善を確かめたことです。3つ目は、GPU 2枚でローカルのAIモデルを動かし、一度に扱える文章の量を増やしたことです。4つ目は、1997年発売の古いPCゲーム『Fallout』のデータを解析し、テキストを中国語に訳して、導入用のパッケージにまとめたことです。

## 1. 複数のAIエージェントに役割を分けて作業する

AIエージェントとは、指示を受けて、調査・コード作成・ブラウザ操作といった作業を自律的に進めるAIです。

### きっかけ

AIに書かせたものを同じAIにレビュー（確認）させると、誤りを見落とすことがありました。そこで、作る役とレビューする役を別のAIに分けました。

### 試したこと

Claude Code、Codex、Antigravityの3つに役割を分けて連携させています。計画・レビュー・受け入れの判定はClaude Code、実装・調査・ブラウザ操作はCodexとAntigravityが担当します。作業の種類（判断・レビュー・実行）と各ツールの利用枠の残りに合わせて、担当するAIを切り替えます。

運用の決まりは次の4つです。

- 作ったAIとは別のAIにレビューさせる
- AI同士の受け渡しは、バージョン番号を付けたファイルで行う
- 同じ対象を複数のAIが同時に編集しないよう、ロック（編集中の印）をかける
- AIが手順を誤ったときは、原因と再発防止策をルール文書に書き足す

作ったAIとは別のAIに確かめさせる進め方は、次の節で述べるPCの不具合調査でも使いました。

### 効果

次の作業に進む前に、別のAIが誤りを見つけるようになりました。

### AIと自分の分担

役割分担、切り替えの基準、レビューの順序は私が決め、ルール文書とスクリプトはAIが書きました。

## 2. ゲーム映像のカクつきの原因調査

### きっかけ

自分のPCで、ゲームの画面が周期的に一瞬止まる症状（カクつき）が出ていたため、原因を調べました。

### 試したこと

サードパーティ製のサービス（Windows標準以外の常駐プログラム）35項目を対象に、再起動を挟みながら11回にわたって比較しました。途中で結果が食い違ったため、実験の設計を検証し直し、候補を4項目に絞りました。

次に、Windowsの動作の記録（ETLトレース）を調べました。描画に時間がかかったフレーム（画面の1コマ）が約1.04秒ごとに74回現れており、その時刻はすべて、1つのサービスのCPU使用率が急に上がった時刻と一致していました。最後に、そのサービスだけを止めた場合と止めない場合を比べました。

### 効果

カクつきは消えました。描画時間が25ミリ秒を超えるフレームは毎分60回から0回になり、全フレームの99%が収まる時間（p99）は9.998ミリ秒から6.578ミリ秒に短くなりました。そのサービスを止めた後は、普段のプレイでもカクつきが出ていません。

### AIと自分の分担

解析とコマンド実行の大部分はAIが行いました。私は再起動のたびにゲームを動かして症状の有無を判定し、結果が食い違ったときは別のAIに実験設計の検証を頼みました。また、35項目を一度にまとめて止める方法は採らないと決めました。改善したかどうかも、フレーム時間の記録を数値と図表で比べて、私が判断しました。

## 3. GPU 2枚でローカルのAIモデルを動かし、扱える文章量を増やす

### きっかけ

Qwen3.8（27B、パラメータ数270億のモデル）が公開された直後に、ローカル環境で動かしました。GPU（RTX 5090）1枚では、深く考えるモード（回答の前に推論を重ねるモード）を使うと、コンテキスト（モデルが一度に扱える文章の量）が足りませんでした。

### 試したこと

GPU 2枚でモデルを動かし、実行用のソフト（Ollama）の設定で、コンテキストの長さを256Kトークンに拡張しました。設定の方法はAIを使って調べました。

### 効果

コンテキストが短かったときは、会話が少し長くなると回答が出なくなっていました。256Kトークンに拡張してからは、深く考えるモードで会話が長くなっても、回答が返ってくるようになりました。

## 4. 古いPCゲーム『Fallout』の中国語化

### 試したこと

2026年に、1997年発売の『Fallout』（1作目）のデータ形式を解析し、テキストを新たに中国語に訳して、ゲーム内で表示できるようにしました。あわせて、一度の操作で導入できるパッケージにまとめました。

### 効果

テキストはすべて中国語になり、ゲームも問題なく遊べます。

### AIと自分の分担

作業の大部分は私が進めました。データ形式の解析とコードの作成はAI（Antigravity）に任せ、AIが訳したテキストは私が校正しました。
